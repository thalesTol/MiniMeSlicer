# MiniMe Slicer (SliceOfMe) — filament looks for Bambu Studio

Fork of Bambu Studio (base: `upstream/master` at 79df7ae30, 2.8.3 beta, 13 Oct 2026).
Branch: `feature/filament-looks`. Remote `upstream` = bambulab/BambuStudio.

## Status (31 Oct 2026, tested by the user)

Done:
- **Filament look window** (`GUI/FilamentLookDialog.*`): one tabbed window for every filament —
  Solid, Gradient, Multi-color, Translucent, Glow — with a filter box, official colours when the preset has them,
  basic palettes, and a 2–4 colour "Make your own" editor. Opened from the colour square in the sidebar
  (`PlaterPresetComboBox::show_filament_look_dialog`).
- **Opacity**: colours stored as `#RRGGBBAA`; `GUI/FilamentColourDialog.*` is the single-colour picker with opacity.
- **Gradient / multi-colour on the model** (Prepare view): `GLVolumeCollection::FilamentLook` in `3DScene.*`,
  `multi_color_*` uniforms in `resources/shaders/{110,140}/gouraud.fs`.
- **Glow**: project option `filament_glow_colour` (per filament, `""` = none), kept in sync in `PresetBundle.cpp`
  and `Plater.cpp`; drawn as a rim glow (`glow_term()` in `gouraud.fs`). Not sent to the printer.
- **Branding**: visible name `SLIC3R_APP_FULL_NAME` = "MiniMe Slicer"; logo files regenerated by
  `tools/branding/make_logo.ps1` (+ hand-written SVGs). `SLIC3R_APP_NAME`/`SLIC3R_APP_KEY` stay "BambuStudio"
  (network plugin, server headers, settings file depend on them).

Open:
- Sliced Preview: gradient / multi-colour / glow drawn in the Summary and ColorPrint views (`u_look_*` uniforms in
  `140/gcode.fs`, `AdvancedRenderer::set_filament_look_uniforms`). Gradient spans the whole print height.
- Sidebar colour square shows no glow halo.
- Curved / polyline cut (new mode next to `CutMode::cutTongueAndGroove`, using `MeshBoolean` minus/intersect).

Goal: three features Bambu Studio lacks.

1. **Opacity levels** — choose a filament's transparency (0–100 %), shown in Prepare and Preview.
2. **Dual / gradient on the model** — draw multi-colour filaments on the 3D model and toolpaths, not only in the swatch.
3. **Glow filaments** — a Glow colour category with a luminous look.

## Feature 1 — Opacity levels

- **Picker:** add an opacity slider (0–100 %) + 8-digit hex field to `FilamentPickerDialog` "custom colour" area. Store via `GetAsString(wxC2S_HTML_SYNTAX)` (already emits `#RRGGBBAA` when not opaque).
- **AMS sync:** keep the user's alpha when re-syncing if the RGB is unchanged (Plater AMS sync, `Plater.cpp` ~4560).
- **Render:** replace the hard "alpha < 0.1 → 30 %" rule with a minimum visible alpha (e.g. clamp to ≥ 0.15) so 0–100 % maps smoothly. Keep it in `adjust_color_for_rendering` so every caller follows.
- **Preview:** confirm the G-code renderers draw transparent tool colours in a separate blended pass after opaque ones (depth test on, depth write off). If not, add that pass (OrcaSlicer PR #16776 is a reference design).
- **Setting:** Preferences toggle "Show filament transparency" (default on).

## Feature 2 — Dual / gradient on the model

- **Data:** read `filament_multi_colour` (up to N colours) + `filament_colour_type` for each extruder.
- **Prepare view:** add uniforms to `gouraud.fs` — `colour_count`, `colours[4]`, `mode` (0 gradient along Z, 1 split/coextruded across X/Y, 2 none) and the object's Z range. Fragment picks/blends colour from `world_pos`.
  Set them in `GLVolume::render` (`3DScene.cpp`) when the volume's filament is multi-colour.
- **Preview:** same idea in `gcode.fs` per toolpath segment, using segment Z (gradient) or a 50/50 split along the extrusion width (dual coextruded).
- **Legend / swatches:** already handled by `FilamentBitmapUtils`.

## Feature 3 — Glow filaments

- **Data:** new `filament_colour_type` value `2` = glow, glow colour in `filament_multi_colour[1]`.
- **Picker:** "Glow" tab in `FilamentPickerDialog` with a few presets (green, blue, aqua, yellow) + custom.
- **Swatch:** radial halo in `FilamentBitmapUtils`.
- **3D:** emissive term in `gouraud.fs` / `gcode.fs` (`emission_factor` already exists in gcode.fs), plus an optional "dark scene" preview toggle.

## Build (Windows)

Tools: Visual Studio 2022 Community, Git, CMake 4.4 (winget `Kitware.CMake`), Strawberry Perl (winget `StrawberryPerl.StrawberryPerl`).
Deps live in `C:\Users\thaleschief\bsdeps` (outside the repo).

Environment for every step (PowerShell):

```powershell
$env:PATH = "C:\Program Files\CMake\bin;C:\Strawberry\perl\bin;" + $env:PATH
$env:CMAKE_POLICY_VERSION_MINIMUM = "3.5"          # CMake 4 vs old deps
$env:PKG_CONFIG_EXECUTABLE = "C:/Strawberry/perl/bin/pkg-config.bat"
```

1. Deps: `build_win.bat -p Community -s deps -d C:\Users\thaleschief\bsdeps`
2. Configure app: `build_win.bat -p Community -s app-cmake -d C:\Users\thaleschief\bsdeps`, then
   `cmake -S . -B build -DCMAKE_INSTALL_PREFIX=C:/Users/thaleschief/SliceOfMe/install_dir -DBBL_RELEASE_TO_PUBLIC=1 -DBBL_INTERNAL_TESTING=0`
   (without the two BBL flags the build is an internal test build: it talks to Bambu's pre-release
   server and the network plugin download fails)
3. Compile at half load: `$env:_CL_ = "/MP4"; cmake --build build --config RelWithDebInfo -- /m:2`
4. Install: `cmake --install build --config RelWithDebInfo`
5. Run with its own settings folder (keeps the installed Bambu Studio untouched):
   `install_dir\bambu-studio.exe --datadir C:\Users\thaleschief\SliceOfMe\devdata`
